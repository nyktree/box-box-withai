# Requisitos

## Funcionais

RF01 autenticar usuários; RF02 gerenciar usuários e perfis; RF03 gerenciar clientes; RF04 gerenciar veículos; RF05 abrir e acompanhar ordens; RF06 registrar avarias e diagnósticos; RF07 sugerir causas; RF08 registrar peças; RF09 consultar histórico; RF10 exportar CSV/PDF.

## Não funcionais

RNF01 interface responsiva e clara; RNF02 persistência relacional; RNF03 integridade por constraints; RNF04 código modular e compreensível; RNF05 instalação reproduzível; RNF06 testes automatizados dos fluxos críticos.

## Atores

Administrador: acesso integral. Atendente: clientes, veículos, abertura e entrega. Mecânico: histórico e dados técnicos das ordens atribuídas.
